Calculus

Q1. The derivative of sin x with respect to x is:

  1. cos x
  2. −cos x
  3. −sin x
  4. tan x
Show answer

A. cos x — d/dx (sin x) = cos x.

Calculus

Q2. The value of ∫ cos x dx is:

  1. sin x + C
  2. −sin x + C
  3. cos x + C
  4. tan x + C
Show answer

A. sin x + C — ∫ cos x dx = sin x + C, since the derivative of sin x is cos x.

Calculus

Q3. The derivative of eˣ with respect to x is:

  1. x eˣ⁻¹
  2. eˣ
  3. 1
  4. ln x
Show answer

B. eˣ — The exponential function is its own derivative: d/dx (eˣ) = eˣ.

Matrices

Q4. The order of a matrix with 2 rows and 3 columns is:

  1. 3 × 2
  2. 2 × 3
  3. 6
  4. 5
Show answer

B. 2 × 3 — Order is written as (rows × columns), so a matrix with 2 rows and 3 columns is of order 2 × 3.

Calculus

Q5. The value of ∫ (1/x) dx is:

  1. x + C
  2. ln|x| + C
  3. −1/x² + C
  4. 1/x² + C
Show answer

B. ln|x| + C — ∫ (1/x) dx = ln|x| + C.

Calculus

Q6. The derivative of any constant function is:

  1. 1
  2. 0
  3. the constant itself
  4. x
Show answer

B. 0 — The derivative of a constant is 0, because a constant function does not change.

Limits

Q7. The value of lim (x→0) (sin x)/x is:

  1. 0
  2. 1
  3. ∞
  4. Undefined
Show answer

B. 1 — This is a standard limit: lim (x→0) (sin x)/x = 1.

Determinants

Q8. The determinant of the 2×2 identity matrix is:

  1. 0
  2. 1
  3. 2
  4. −1
Show answer

B. 1 — The identity matrix [[1,0],[0,1]] has determinant (1)(1) − (0)(0) = 1.

Calculus

Q9. The derivative of x³ with respect to x is:

  1. 3x²
  2. x²
  3. 3x
  4. x⁴/4
Show answer

A. 3x² — By the power rule, d/dx (xⁿ) = n·xⁿ⁻¹, so d/dx (x³) = 3x².

Probability

Q10. If P(A) = 0.6, then the probability of 'not A' is:

  1. 0.6
  2. 0.4
  3. 1.6
  4. 0
Show answer

B. 0.4 — P(not A) = 1 − P(A) = 1 − 0.6 = 0.4.

Relations And Functions

Q11. The function f: R → R defined by f(x) = x² is:

  1. one-one and onto
  2. one-one but not onto
  3. onto but not one-one
  4. neither one-one nor onto
Show answer

D. neither one-one nor onto — Since f(1) = f(-1) = 1, f is not one-one; and no negative real number is an output, so with codomain R it is not onto. Hence it is neither one-one nor onto.

Inverse Trigonometric Functions

Q12. The principal value of sin⁻¹(sin(2π/3)) is:

  1. 2π/3
  2. π/6
  3. π/3
  4. -π/3
Show answer

C. π/3 — Since 2π/3 lies outside [-π/2, π/2], use sin(2π/3) = sin(π - 2π/3) = sin(π/3) = √3/2. Thus sin⁻¹(√3/2) = π/3.

Matrices

Q13. Every element on the main diagonal of a skew-symmetric matrix is equal to:

  1. 1
  2. equal to its trace
  3. 0
  4. undefined
Show answer

C. 0 — A skew-symmetric matrix satisfies aᵢⱼ = -aⱼᵢ. For diagonal entries aᵢᵢ = -aᵢᵢ, giving 2aᵢᵢ = 0, so every diagonal element is 0.

Determinants

Q14. If A is a 3 × 3 matrix with |A| = 5, then the value of |2A| is:

  1. 10
  2. 20
  3. 30
  4. 40
Show answer

D. 40 — For an n × n matrix, |kA| = kⁿ|A|. Here n = 3, so |2A| = 2³ × 5 = 8 × 5 = 40.

Continuity And Differentiability

Q15. The function f(x) = |x| is:

  1. continuous everywhere but not differentiable at x = 0
  2. differentiable everywhere
  3. discontinuous at x = 0
  4. neither continuous nor differentiable at x = 0
Show answer

A. continuous everywhere but not differentiable at x = 0 — |x| is continuous for all real x, but at x = 0 the left-hand derivative (-1) and right-hand derivative (+1) differ, so it is not differentiable there.

Application Of Derivatives

Q16. The function f(x) = x² - 4x + 3 has a local minimum at x =:

  1. -2
  2. 2
  3. 0
  4. 4
Show answer

B. 2 — f'(x) = 2x - 4 = 0 gives x = 2, and f''(x) = 2 > 0, confirming a minimum at x = 2.

Integrals

Q17. ∫ sec²x dx equals:

  1. tan x + C
  2. -cot x + C
  3. sec x tan x + C
  4. cot x + C
Show answer

A. tan x + C — Since d/dx(tan x) = sec²x, the integral of sec²x is tan x + C.

Application Of Integrals

Q18. The area of the region bounded by the line y = x, the x-axis, and the lines x = 0 and x = 2 is:

  1. 1
  2. 4
  3. 8
  4. 2
Show answer

D. 2 — The area = ∫₀² x dx = [x²/2]₀² = 4/2 = 2 (equivalently, a right triangle of base 2 and height 2).

Differential Equations

Q19. The order of the differential equation d²y/dx² + 3(dy/dx)³ + y = 0 is:

  1. 2
  2. 1
  3. 3
  4. 0
Show answer

A. 2 — Order is the highest derivative present. Here the highest is d²y/dx², so the order is 2 (the cube affects degree, not order).

Vector Algebra

Q20. If a and b are two non-zero vectors such that a · b = 0, then a and b are:

  1. parallel
  2. perpendicular
  3. equal
  4. anti-parallel
Show answer

B. perpendicular — a · b = |a||b|cosθ. Since a and b are non-zero, a · b = 0 forces cosθ = 0, i.e. θ = 90°, so the vectors are perpendicular.

Three Dimensional Geometry

Q21. The direction cosines of the y-axis are:

  1. (0, 1, 0)
  2. (1, 0, 0)
  3. (0, 0, 1)
  4. (1, 1, 1)
Show answer

A. (0, 1, 0) — The y-axis makes 90°, 0°, 90° with the x, y, z axes respectively, giving direction cosines (cos90°, cos0°, cos90°) = (0, 1, 0).

Linear Programming

Q22. In a linear programming problem, the feasible region is always:

  1. a circle
  2. always unbounded
  3. a convex set
  4. a single point
Show answer

C. a convex set — The feasible region is the intersection of half-planes defined by linear constraints, and such an intersection is always a convex set.

Probability

Q23. If A and B are independent events with P(A) = 0.5 and P(B) = 0.4, then P(A ∪ B) equals:

  1. 0.9
  2. 0.7
  3. 0.2
  4. 0.1
Show answer

B. 0.7 — For independent events P(A ∩ B) = P(A)P(B) = 0.2, so P(A ∪ B) = P(A) + P(B) - P(A ∩ B) = 0.5 + 0.4 - 0.2 = 0.7.

Probability

Q24. If P(A ∩ B) = 0.2 and P(B) = 0.5, then the conditional probability P(A | B) is:

  1. 0.4
  2. 0.1
  3. 0.7
  4. 1.0
Show answer

A. 0.4 — P(A | B) = P(A ∩ B) / P(B) = 0.2 / 0.5 = 0.4.

Integrals

Q25. ∫ 1/(1 + x²) dx equals:

  1. sin⁻¹x + C
  2. tan⁻¹x + C
  3. log|1 + x²| + C
  4. sec⁻¹x + C
Show answer

B. tan⁻¹x + C — The standard result is ∫ dx/(1 + x²) = tan⁻¹x + C, since d/dx(tan⁻¹x) = 1/(1 + x²).

Continuity And Differentiability

Q26. The derivative of tan x with respect to x is:

  1. sec x tan x
  2. sec²x
  3. -cosec²x
  4. -sin x
Show answer

B. sec²x — Writing tan x = sin x / cos x and applying the quotient rule gives d/dx(tan x) = sec²x.
