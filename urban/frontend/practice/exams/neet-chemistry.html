Periodic Table

Q1. The number of protons in the nucleus of an atom is called its:

  1. Mass number
  2. Atomic number
  3. Valency
  4. Atomic mass
Show answer

B. Atomic number — The atomic number equals the number of protons and defines the element. The mass number is protons + neutrons.

Inorganic Chemistry

Q2. Which of the following is a noble (inert) gas?

  1. Oxygen
  2. Chlorine
  3. Argon
  4. Nitrogen
Show answer

C. Argon — Argon is a noble gas (Group 18) with a full outer electron shell, making it chemically inert. Oxygen, chlorine and nitrogen are reactive non-metals.

Chemical Bonding

Q3. The valency of carbon is:

  1. 2
  2. 3
  3. 4
  4. 6
Show answer

C. 4 — Carbon has 4 electrons in its outer shell and forms 4 covalent bonds, so its valency is 4. (6 is its atomic number, a different quantity.)

Physical Chemistry

Q4. An acid turns blue litmus paper:

  1. Red
  2. Green
  3. Yellow
  4. Blue (no change)
Show answer

A. Red — Acids turn blue litmus red. Bases turn red litmus blue. Litmus is a common acid–base indicator.

Periodic Table

Q5. The most electronegative element in the periodic table is:

  1. Oxygen
  2. Chlorine
  3. Fluorine
  4. Nitrogen
Show answer

C. Fluorine — Fluorine is the most electronegative element (about 4.0 on the Pauling scale), i.e. it attracts bonding electrons most strongly.

Inorganic Chemistry

Q6. The chemical formula of water is:

  1. H₂O₂
  2. H₂O
  3. CO₂
  4. HO
Show answer

B. H₂O — Water is H₂O — two hydrogen atoms bonded to one oxygen atom. H₂O₂ is hydrogen peroxide and CO₂ is carbon dioxide.

Mole Concept

Q7. How many oxygen atoms are present in 0.5 mol of carbon dioxide (CO2)? (N_A = Avogadro's number)

  1. N_A
  2. 0.5 N_A
  3. 2 N_A
  4. 3 N_A
Show answer

A. N_A — Each CO2 molecule has 2 oxygen atoms, so 0.5 mol CO2 contains 0.5 x 2 = 1 mol of O atoms = N_A oxygen atoms.

Atomic Structure

Q8. Which of the following sets of quantum numbers (n, l, m, s) is NOT permissible for an electron?

  1. n=3, l=2, m=-1, s=+1/2
  2. n=2, l=1, m=0, s=-1/2
  3. n=1, l=1, m=0, s=+1/2
  4. n=4, l=3, m=+2, s=-1/2
Show answer

C. n=1, l=1, m=0, s=+1/2 — For a given n, l can only take values from 0 to (n-1). With n=1, l must be 0, so l=1 is not allowed.

Periodic Properties

Q9. Which of the following elements has the highest first ionization enthalpy?

  1. Boron
  2. Carbon
  3. Oxygen
  4. Nitrogen
Show answer

D. Nitrogen — Nitrogen has a half-filled 2p3 configuration, which is extra stable, so removing an electron is harder; hence IE1 of N is greater than that of O (which lies to its right).

Chemical Bonding

Q10. The hybridization of the central atom and the molecular shape of XeF4 are respectively:

  1. sp3d and see-saw
  2. sp3d2 and square planar
  3. sp3 and tetrahedral
  4. sp3d2 and octahedral
Show answer

B. sp3d2 and square planar — Xe in XeF4 has 4 bond pairs and 2 lone pairs (6 electron domains), giving sp3d2 hybridization; the two lone pairs occupy axial positions, leaving a square planar shape.

Thermodynamics

Q11. For a chemical reaction to be spontaneous at all temperatures, the signs of the enthalpy change (ΔH) and entropy change (ΔS) should be:

  1. ΔH negative, ΔS positive
  2. ΔH positive, ΔS negative
  3. ΔH negative, ΔS negative
  4. ΔH positive, ΔS positive
Show answer

A. ΔH negative, ΔS positive — ΔG = ΔH - TΔS. When ΔH is negative and ΔS is positive, ΔG is negative at every temperature, so the reaction is spontaneous at all temperatures.

Ionic Equilibrium

Q12. The pH of a 0.001 M aqueous solution of HCl (a strong acid) is:

  1. 2
  2. 3
  3. 4
  4. 11
Show answer

B. 3 — HCl fully dissociates, so [H+] = 0.001 = 10^-3 M, and pH = -log(10^-3) = 3.

Redox Reactions

Q13. The oxidation number of chromium in potassium dichromate (K2Cr2O7) is:

  1. +3
  2. +7
  3. +6
  4. +2
Show answer

C. +6 — Let Cr be x: 2(+1) + 2x + 7(-2) = 0, giving 2x = 12, so x = +6.

Chemical Kinetics

Q14. The half-life of a first-order reaction is independent of the:

  1. rate constant
  2. temperature
  3. activation energy
  4. initial concentration of reactant
Show answer

D. initial concentration of reactant — For a first-order reaction, t(1/2) = 0.693/k, which does not contain the initial concentration; hence half-life is independent of initial concentration (but depends on k, which varies with temperature and activation energy).

Solutions Colligative

Q15. Among the following 0.1 molal aqueous solutions, which one shows the highest boiling point elevation?

  1. Glucose
  2. Sodium chloride
  3. Calcium chloride
  4. Urea
Show answer

C. Calcium chloride — Boiling point elevation is proportional to the van't Hoff factor i. CaCl2 dissociates into 3 ions (i≈3), more than NaCl (i≈2) or the non-electrolytes glucose and urea (i=1), so it gives the greatest elevation.

Coordination Compounds

Q16. The oxidation state of iron in potassium ferrocyanide, K4[Fe(CN)6], is:

  1. +2
  2. +3
  3. +4
  4. 0
Show answer

A. +2 — Each K is +1 (total +4) and each CN is -1 (total -6). For neutrality: 4 + x + (-6) = 0, so x = +2.

P Block Elements

Q17. Which of the following is the strongest acid?

  1. HClO
  2. HClO2
  3. HClO3
  4. HClO4
Show answer

D. HClO4 — As the oxidation state of chlorine and the number of oxygen atoms increase, the conjugate base is more stabilized by charge delocalization, so acid strength increases: HClO4 is the strongest of these oxoacids.

D Block Elements

Q18. Which of the following ions is colourless in aqueous solution?

  1. Cu2+
  2. Sc3+
  3. Fe2+
  4. Ni2+
Show answer

B. Sc3+ — Colour in transition-metal ions arises from d-d transitions. Sc3+ has a d0 configuration (empty d subshell), so no d-d transition is possible and it is colourless.

General Organic Chemistry

Q19. Which of the following carbocations is the most stable?

  1. CH3+ (methyl)
  2. CH3CH2+ (ethyl)
  3. (CH3)2CH+ (isopropyl)
  4. (CH3)3C+ (tert-butyl)
Show answer

D. (CH3)3C+ (tert-butyl) — More alkyl groups attached to the positive carbon donate electron density through +I effect and hyperconjugation, stabilizing the cation. The tertiary tert-butyl cation is the most stable.

Hydrocarbons Isomerism

Q20. The number of possible structural (chain) isomers of pentane, C5H12, is:

  1. 2
  2. 3
  3. 4
  4. 5
Show answer

B. 3 — C5H12 has three chain isomers: n-pentane, isopentane (2-methylbutane), and neopentane (2,2-dimethylpropane).

Aldehydes Ketones

Q21. Which of the following compounds gives a positive Tollens' (silver mirror) test?

  1. Ethanal (CH3CHO)
  2. Propanone (acetone)
  3. Ethanol
  4. Diethyl ether
Show answer

A. Ethanal (CH3CHO) — Tollens' reagent is reduced by aldehydes, which are oxidized to carboxylate ions, depositing a silver mirror. Ethanal is an aldehyde; ketones, alcohols, and ethers do not respond.

Biomolecules

Q22. Which of the following carbohydrates is a non-reducing sugar?

  1. Glucose
  2. Maltose
  3. Sucrose
  4. Fructose
Show answer

C. Sucrose — In sucrose the anomeric carbons of glucose and fructose are joined by the glycosidic linkage, leaving no free anomeric (hemiacetal) group, so it cannot reduce Tollens'/Fehling's reagent and is non-reducing.
